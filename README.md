# Excel Sales Dashboard

An interactive Excel dashboard designed to analyze and summarize key sales performance metrics, customer behavior, and product trends to support data-driven business decisions.

---

## 📊 Project Overview

This project transforms raw transactional sales data into an interactive visual dashboard. It tracks revenue performance, order volume, geographical sales distribution, top-performing product categories, and key sales channels.

### Key Objectives
* **Analyze Sales Performance:** Track total revenue, order count, total quantity sold, and average order value (AOV).
* **Identify Regional Trends:** Visualize geographical distribution of revenue across different regions/markets.
* **Product Category Performance:** Determine best-selling products and top-revenue categories.
* **Time-Series Analysis:** Uncover monthly, quarterly, and year-over-year growth trends.
* **Interactive Filtering:** Allow stakeholders to slice and dice data dynamically using Slicers.

---

## 🛠️ Built With

* **Microsoft Excel:** PivotTables, PivotCharts, Advanced Formulas (`XLOOKUP`, `INDEX/MATCH`, `SUMIFS`, `COUNTIFS`), Data Validation, Slicers, and Conditional Formatting.

---

## 📈 Dashboard Features & KPIs

1. **KPI Cards / Summary Metrics:**
   * **Total Revenue:** Overall income generated.
   * **Total Orders:** Total number of completed transactions.
   * **Total Quantity Sold:** Aggregate volume of units sold.
   * **Average Order Value (AOV):** Revenue generated per transaction.

2. **Visualizations:**
   * **Sales Trend over Time:** Line chart illustrating monthly/quarterly sales performance.
   * **Revenue by Region:** Bar chart highlighting high-performing sales territories.
   * **Sales by Category / Sub-Category:** Donut or bar charts showing revenue contribution by product group.
   * **Top 5 / Bottom 5 Products:** Sorted chart pinpointing key revenue drivers and underperforming SKUs.
   * **Payment / Ship Mode Breakdown:** Column chart depicting preferred customer delivery options.

3. **Interactivity:**
   * **Dynamic Slicers:** Filter the entire dashboard by Year, Quarter, Region, Segment, and Product Category.

## 🚀 How to Use the Dashboard

1. **Download the File:** Clone or download the `excel project 1.xlsx` file from this repository.
2. **Open in Microsoft Excel:** Open the file using Microsoft Excel 2016 or newer for full feature compatibility (Slicers and Pivot Charts).
3. **Navigate Sheets:**
   * `Raw_Data`: Source transactional data.
   * `Data_Cleaning`: Processed data with calculated columns.
   * `Pivot_Tables`: Underlying pivot summary tables powering the charts.
   * `Dashboard`: Main visual report interface.
4. **Interact:** Use the Slicer buttons on the `Dashboard` tab to filter metrics dynamically.

## 💡 Key Business Insights

* **Peak Sales Periods:** Highest revenue surges occur towards Q4 (holiday season).
* **Top Revenue Region:** Certain regions consistently contribute over 30%+ of total revenue.
* **Product Mix:** A small subset of top product SKUs drive the majority of profits.
